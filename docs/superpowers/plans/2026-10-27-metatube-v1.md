# MetaTube v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the MetaTube Claude Code plugin: `/metatube:setup`, `/metatube:generate`,
`/metatube:publish --mode update|upload`, driving ytstudio-cli 0.4.2.

**Architecture:** The repo root is the plugin. Claude's reasoning lives in markdown (commands,
`SKILL.md`, references). Everything deterministic — sidecar discovery, schema lint, safe
`video_id` write-back, title matching, building and running ytstudio argv with `PYTHONUTF8=1`,
quota estimates, config — lives in a small tested Python helper (`metatube-helper`) inside the
skill directory, which prints JSON for Claude to read. Claude never hand-quotes multi-line
descriptions into a shell; the helper passes argv lists to `subprocess.run`.

**Tech Stack:** Python ≥ 3.12, uv, ruamel.yaml ≥ 0.18 (round-trip YAML, keeps comments),
pydantic ≥ 2.5, pytest. ytstudio-cli 0.4.2 (external, on PATH). Claude Code plugin format.

**Spec:** `docs/superpowers/specs/2026-10-27-metatube-design.md` (read §3, §5–§8 before starting).

**Branch:** all work on `feat/metatube-v1` (already created). Never commit to `main`.

## Global Constraints

- ytstudio pinned: `PINNED_VERSION = "0.4.2"`; install command `uv tool install ytstudio-cli==0.4.2`.
- Supported video extensions: `.mp4 .mov .mkv .webm`. Flag (not skip silently) `.avi .wmv .m4v .flv .mpg .mpeg .3gp`.
- Sidecar keys allowed (ytstudio `extra=forbid`): `title, description, privacy, publish_at, tags, category_id, default_language, default_audio_language, made_for_kids, video_id, uploaded_at`. Nothing else, ever.
- Defaults: `privacy: public`, `category_id: "28"`, `default_language: en`, `default_audio_language: en`, `made_for_kids: false`.
- Title 1–100 chars (aim ≤ 70). Tags 8–15, total ≤ 500 chars, no tag may contain a comma (ytstudio `--tags` splits on commas).
- `publish_at` must be timezone-aware and in the future; it forces `privacy: private`.
- Every ytstudio subprocess gets `PYTHONUTF8=1` and `PYTHONIOENCODING=utf-8`; all helper file IO is explicit `encoding="utf-8"`.
- Never change or remove an existing `video_id`. Never `--execute` without the user's explicit yes in-session (enforced in SKILL.md; helper defaults to dry-run).
- Never read/print/copy client secrets or ytstudio token files; the helper never opens anything under `~/.config/ytstudio-cli/` except checking that `client_secrets.json` exists.
- Quota constants: upload 1600 units, update 50, list 1, daily 10000, safe uploads/day 6.
- Config at `~/.config/metatube/config.yaml`, overridable by env `METATUBE_CONFIG` (tests use this). Identifiers only.
- Commands: `/metatube:setup`, `/metatube:generate`, `/metatube:publish`.

## Review Focus

1. Long multi-line descriptions with quotes, `$`, backticks, em dashes and `é` — must reach ytstudio byte-exact on Windows (argv list, no shell; UTF-8 env). Pinned in Task 6 and Task 9.
2. A sidecar that already has `video_id` being rewritten by a regenerate or a second match — `video_id` must survive untouched or the write must fail. Pinned in Task 2.
3. Two local files whose stems match the same channel title, or a channel video already claimed by another sidecar — must come back `ambiguous`/excluded, never auto-matched. Pinned in Task 5.
4. Folder with one video missing its sidecar in upload mode — must switch to per-file, not fail the whole folder. Pinned in Task 6.
5. Expired login (7-day Testing expiry) — `auth-check` must say `expired`, and publish must stop before spending quota. Pinned in Task 6 (classification) and Task 8 (SKILL.md flow).

### Task 7: JSON CLI

**Files:**
- Create: `src/metatube_helper/cli.py`
- Test: `tests/test_cli.py`

**Interfaces:**
- Consumes: everything from Tasks 1–6
- Produces: `main(argv: list[str] | None = None) -> int`. Every subcommand prints exactly one JSON object to stdout (UTF-8, `ensure_ascii=False`) and returns the exit code. Profile comes from `load_config().ytstudio_profile`.

| Subcommand | Output keys | Exit |
| --- | --- | --- |
| `discover FOLDER` | `to_jsonable(Discovery)` + `fully_paired` | 0 (2 if folder missing) |
| `lint PATH` (file or folder) | `{"results": {path: {"errors": [...], "warnings": [...]}}, "ok": bool}` | 0 if ok else 1 |
| `auth-check` | `{"status", "detail", "installed_version", "pinned_version"}` | 0 if `ok` else 1 |
| `match FOLDER [--limit N]` | `{"matches": [Match…]}` | 0; 1 if listing fails |
| `set-video-id SIDECAR REF` | `{"sidecar", "video_id"}` | 0; 1 on `LiveSidecarError`/bad ref |
| `update SIDECAR [--execute]` | `{"argv", "returncode", "stdout", "stderr", "studio_url"}` — needs `video_id` in sidecar, else exit 1 with `{"error": "no video_id; run match first"}` | ytstudio's code |
| `upload FOLDER [--execute] [--max N]` | `{"plan": UploadPlan, "results": [RunResult…], "now_live": [stems with video_id after run], "audit_passed": bool}` | last result's code |

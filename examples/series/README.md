# Example: series

A two-part "tinyqueue Deep Dive" series about the fictional `tinyqueue` GitHub repo.

- `episode-01.md` + `episode-01.srt`: script and transcript, so the sidecar gets chapters
- `episode-02.md`: script only, so no chapters (MetaTube never guesses timestamps)
- `episode-0N.yaml`: the sidecars MetaTube would produce after review
- `episode-0N.mp4`: your rendered videos (not committed)

Try it: `/metatube:generate examples/series`
